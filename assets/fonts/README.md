# Pixelify Sans

Pixelify Sans by the Pixelify Sans Project Authors, licensed under the bundled SIL Open Font License (`OFL.txt`).

Source: https://github.com/google/fonts/tree/main/ofl/pixelifysans

`PixelifySans.ttf` is a static regular (400) instance of the upstream variable font, generated with fontTools for consistent iOS, Android, and web rendering. It is bundled locally and loaded using Expo Font; no font service is contacted at runtime.

# Roboto Mono

`RobotoMono-Bold.ttf` is the upstream static bold font used for the brand, main page titles, and loading-screen title. It is bundled locally and loaded through Expo Font on web, iOS, and Android.

Source: https://github.com/googlefonts/RobotoMono/blob/main/fonts/ttf/RobotoMono-Bold.ttf

License: SIL Open Font License, included in `RobotoMono-OFL.txt`.
